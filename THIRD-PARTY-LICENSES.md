# Third-party licenses

The SDK itself is MIT-licensed (see [LICENSE](LICENSE)). The library also contains the 208 third-party crates below, each under its own license. All of them are permissive or offer a permissive choice; where a crate offers several licenses ("MIT OR Apache-2.0"), you may use it under either.

Two that come with a condition worth knowing:

- **UniFFI** (`uniffi*`, MPL-2.0): file-level copyleft. Using it, as the SDK does, puts no condition on your code or the SDK's; only changes to UniFFI's own source files would have to be published under MPL-2.0.
- **webpki-roots** (CDLA-Permissive-2.0): Mozilla's list of trusted certificate authorities, used for `https://` endpoints. If you distribute it, include its license text (it's in the crate).

Generated by `scripts/third-party-licenses.py` from `Cargo.lock`. Regenerate after changing dependencies.
